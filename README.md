# Han AEO v1

Reusable Codex skill for evidence-governed AEO, AI SEO, entity SEO, keyword/page mapping, approval-gated implementation, browser-assisted verification, and measurement.

## Contents

- `han-aeo-v1/` - the reusable skill.
- `examples/mock-aeo-project/` - sanitized sample project material for testing the workflow.
- `UPLOAD_REVIEW.md` - pre-upload safety review notes.

## Safety Notes

This repository is intended to be public-safe. Real client source archives, private business details, credentials, Search Console exports, analytics exports, and logged-in screenshots should not be committed.

The original customer workflow archive used to build this skill was moved out of the repository and replaced with a mock example.
