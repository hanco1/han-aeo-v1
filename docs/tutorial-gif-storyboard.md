## Chrome Recording Rules

Use Chrome only after the Codex Chrome Extension is installed and enabled for the selected Chrome profile.

Before recording:

1. Use a fresh browser window.
2. Zoom to 100 percent.
3. Hide bookmarks if they contain private names.
4. Log out of unrelated accounts.
5. Prepare fake `.env` values.
6. Decide whether to blur or skip secret reveal moments.

Do not record:

- real API key values;
- account email;
- billing pages;
- usage dashboards;
- organization IDs;
- private project names;
- browser password manager prompts.
